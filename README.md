# モンスターあわせ ― アイコン神経衰弱

伏せたカードを2枚めくって、同じモンスターをそろえる神経衰弱。HTMLプレイヤーのカートリッジ。

- 遊ぶ: https://oosawak.github.io/monster-awase/
- アイコンは RPG Awesome（アイコンフォント、SIL OFL 1.1）を使用。フォントファイルはプレイヤー側（html-player リポジトリの assets/）が供給し、ゲーム本体には含めない方式。そのため、URL埋め込み（#p=）でもアイコンが使える
- 単一HTML、約3.8KB。埋め込みURLも X の4,096文字に収まる
